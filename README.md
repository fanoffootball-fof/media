# media — @fanoffootball

Vidéos TikTok de @fanoffootball, générées en code (aucune image de match, photo de joueur ou musique protégée).

- `videos/` : vidéos publiées via Metricool (liens bruts GitHub).
- `specs/` : description JSON de chaque vidéo ; `specs/exemples/` pour les modèles.
- `tools/` : générateur (`make_video.py`, `engine.py`, `music.py`) et format des specs (`tools/SPEC.md`).
- `PIPELINE.md` : procédure de production quotidienne suivie par la tâche planifiée.
- `journal.md` : historique des publications.
